# Telegram Employee Tracker

Бот собирает базу сотрудников: заходит в ваш личный аккаунт (как userbot через Telethon),
мониторит указанные группы (в т.ч. группы с темами/топиками) 24/7 и добавляет юзернеймы новых
людей в SQLite-базу, пропуская тех, кто там уже есть. Управление — через отдельного
Telegram-бота с меню.

## 1. Получите данные для конфига

1. **API_ID / API_HASH** — зайдите на https://my.telegram.org → «API development tools» →
   создайте приложение → скопируйте `api_id` и `api_hash`.
2. **BOT_TOKEN** — создайте бота через **@BotFather** (`/newbot`), скопируйте токен.
3. **OWNER_IDS** — узнайте свой числовой Telegram ID через **@userinfobot**. Если управлять
   ботом будет несколько человек — перечислите ID через запятую.

## 2. Залейте код на GitHub

```bash
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin <ваш_репозиторий>
git push -u origin main
```

`.env` и `*.db` в репозиторий не попадут — они в `.gitignore`.

## 3. Разверните на Render

1. Render → **New → Web Service** → подключите ваш GitHub-репозиторий.
2. Environment: **Python 3**.
3. Build command: `pip install -r requirements.txt`
4. Start command: `python main.py`
5. В разделе **Environment** добавьте переменные:
   - `API_ID`
   - `API_HASH`
   - `BOT_TOKEN`
   - `OWNER_IDS`
   - `SESSION_STRING` (оставьте пустым — заполните после первого входа, см. ниже)
   - `DB_PATH` (можно оставить `employees.db`, см. предупреждение ниже)
6. Деплой.

### ⚠️ Про хранение базы данных на Render

Файловая система бесплатного/стандартного Web Service на Render **эфемерная**:
при каждом редеплое или рестарте контейнера файлы (включая SQLite-базу) стираются.
Варианты:

- Подключить **Render Persistent Disk** (платная опция) и указать `DB_PATH=/var/data/employees.db`.
- Периодически выгружать базу через кнопку «Скачать базу (CSV)» в боте.
- Перенести хранение в внешнюю БД (Postgres и т.п.) — база сделана так, что класс `Database`
  легко заменить на аналогичный с другим бэкендом.

## 4. Первый запуск и вход в аккаунт

1. Откройте вашего управляющего бота в Telegram, отправьте `/start`.
2. Нажмите **«🔑 Войти в аккаунт»**, введите номер телефона, затем код, который придёт
   вам в официальном Telegram-приложении, при необходимости — пароль 2FA.
3. После успешного входа бот пришлёт строку сессии (`SESSION_STRING`) — скопируйте её
   и добавьте как переменную окружения в Render (Environment → Add). Это нужно,
   чтобы после рестарта сервиса не входить заново.

## 5. Добавление групп и запуск мониторинга

1. **«➕ Добавить группу»** — отправьте ссылку (`https://t.me/...`), `@username` или числовой
   ID чата (например, `-1001234567890`). Можно добавить несколько групп подряд, затем `/done`.
2. **«▶️ Запустить мониторинг»** — с этого момента бот слушает все указанные группы
   (включая все темы в группах-форумах) и добавляет новых людей в базу.
   Мониторинг стартует **с текущего момента**, историю чата с самого начала бот не сканирует.
3. **«📥 Скачать базу (CSV)»** — выгрузить текущий список сотрудников.
4. **«📊 Статистика»** — количество найденных сотрудников и групп на мониторинге.

## Структура проекта

- `config.py` — все настройки берутся из переменных окружения.
- `database.py` — SQLite: таблицы `groups` и `employees`.
- `userbot.py` — Telethon-клиент: логин и обработчик новых сообщений.
- `bot.py` — управляющий бот на python-telegram-bot (меню, диалоги).
- `main.py` — точка входа: Flask health-check (для Render) + запуск бота и юзербота.

## Важно

Используйте это только для своих собственных групп/чатов компании и с ведома участников
о том, что их данные (юзернейм, ID) сохраняются в корпоративную базу — это персональные
данные, и на них может распространяться местное законодательство (например, GDPR),
даже если участники — ваши сотрудники.
